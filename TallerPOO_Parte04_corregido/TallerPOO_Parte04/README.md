# TallerPOO_Parte04 (C# / .NET 10)

Proyecto de consola práctico que integra todos los conceptos de la **Parte 04 (Programación Orientada a Objetos, págs. 1–66)**:
- Clases, objetos, constructores y sobrecarga
- Encapsulación, propiedades y miembros estáticos
- Herencia (`base`), clases selladas (`sealed`) y polimorfismo (`virtual` / `override`)
- Clases abstractas (`abstract`) e interfaces (`interface`)
- Composición y agregación
- Patrones de diseño (*Singleton* y *Strategy*)
- Principios SOLID

## Cómo ejecutarlo
1. Descomprime el archivo `.zip`.
2. Abre la carpeta en **Visual Studio Code** o abre `TallerPOO_Parte04.csproj` y ejecuta `dotnet run` en la terminal.
